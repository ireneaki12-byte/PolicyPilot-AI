# AI Tooling

## Tools Used

I used AI coding assistance to help with:

- Understanding the assignment requirements
- Designing the RAG architecture
- Creating starter code for ingestion, retrieval, and the web application
- Drafting documentation
- Debugging errors
- Creating evaluation questions

## What Worked Well

AI assistance was helpful for quickly generating boilerplate code, explaining unfamiliar concepts, and suggesting a clean project structure.

## What Did Not Work Well

Some generated code required manual correction, especially around imports, environment variables, and deployment configuration.
